# Verwalto Website · Version 2

Apple-inspirierte, eigenständige Website mit:

- Animiertem Verbindungsnetzwerk für Verwalto-Idee und Markenmottos
- Sprachumschalter für Deutsch, Englisch, Französisch, Spanisch und Mandarin
- Größerer, besser lesbarer Typografie
- Sanften Scroll-Reveals, Fortschrittsleiste und dezenter Parallax-Vorschau
- Rücksicht auf Systemeinstellungen für reduzierte Bewegung

## Lokal ansehen

`index.html` im Browser öffnen. Das Formular zeigt eine Bestätigung, speichert oder versendet aber keine E-Mail-Adresse. Preise sind geplante Monatspreise; Checkout ist nicht angeschlossen.

Die Installationsanleitung liegt als `INSTALLATION.md` bei und beschreibt den Stand der Entwicklungsfassung.
